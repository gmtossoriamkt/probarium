# Список вопросов по итогам UX/контент-аудита

Ниже — все места, где для завершения правки не хватает реальных фактов (цифры, названия партнёров, документы). Вместо того чтобы придумывать эти данные, в код вставлены заметные плейсхолдеры `[TODO: ...]`. Это их сводный список.

## 1. Список аккредитованных партнёрских центров и лабораторий
**Где:** [licenzii-sertifikaty/index.html](licenzii-sertifikaty/index.html)
Блок «Разрешительные документы» с плейсхолдерами «будет опубликовано» заменён на блок про сеть аккредитованных партнёрских центров/лабораторий. Нужен реальный список (или хотя бы типы) партнёров, чтобы блок не остался пустым.

## 2. Применимость ISO 14155
**Где:** [index.html](index.html) — хиро-блок, полоса стандартов
В список стандартов первого экрана добавлен ГОСТ Р ИСО 14155 (испытания МИ с участием человека) как более релевантный клиническим испытаниям МИ, чем убранные ISO 9001/27001. Нужно подтвердить, что компания действительно ориентируется на этот стандарт в работе.

## 3. Типы медицинских центров-партнёров
**Где:** [klinicheskie-ispytaniya-medizdeliy/s-uchastiem-cheloveka/index.html](klinicheskie-ispytaniya-medizdeliy/s-uchastiem-cheloveka/index.html)
Формулировка «Многопрофильные клинические центры» оставлена как есть (не заменена на федеральные медцентры / НМИЦ / медцентры ДЗМ и т.п.), так как нет подтверждённого списка реальных партнёров. Нужно уточнить, с какими типами учреждений Probarium работает по факту.

## 4. Стоимость кейса токсикологии/биосовместимости
**Где:** [kejsy/index.html](kejsy/index.html), [doklinicheskie-issledovaniya/index.html](doklinicheskie-issledovaniya/index.html)
Для кейсов КИ, ИВД, ЭМС и валидации ПО ориентир стоимости добавлен на основе уже опубликованных базовых цен из [kalkulyator/index.html](kalkulyator/index.html). Для кейса «Биологическая оценка по ГОСТ ISO 10993» сопоставимой цифры в материалах сайта нет — нужен реальный ориентир стоимости.

## 5. Недостающие PDF в разделе НПА
**Где:** [npa/index.html](npa/index.html)
Часть пунктов НПА сделана скачиваемой — ссылки ведут на реально существующие PDF в `/biblioteka/files`. Но для 4 позиций подходящего файла в библиотеке нет: **323-ФЗ**, **ГОСТ Р 72071-2025**, **ГОСТ Р ИСО 20916-2022**, **ГОСТ Р 56429-2021**. Нужны актуальные PDF для них.

## 6. Внутренний чек-лист документов регистрационного досье
**Где:** [registraciya-medizdeliy/index.html](registraciya-medizdeliy/index.html)
Страница переработана: добавлен раздел «Что входит в регистрационное досье» с общим составом документов по публичным регуляторным требованиям (323-ФЗ, ПП №1684, Решение ЕЭК о классификаторе видов документов досье). Это общий, а не внутренний список Probarium — если нужен именно фирменный чек-лист, его нужно предоставить отдельно.

## 7. Реальные сроки этапов
**Где:** [tehnicheskie-ispytaniya-medizdeliy/validaciya-po/index.html](tehnicheskie-ispytaniya-medizdeliy/validaciya-po/index.html) (флаг проставлен явно)
Цифры сроков («от 4 недель» для валидации ПО класса A, «от 2 недель» для клинических этапов и т.д.) не менялись — это уже существовавшие на сайте значения, их достоверность не проверялась в рамках этого аудита. Явный TODO оставлен на странице валидации ПО как показательный пример; та же оговорка фактически применима ко всем аналогичным блокам «Сроки и цена» на сайте (клиника, доклиника, техиспытания, регистрация, дорожная карта, калькулятор) — рекомендуется одним заходом сверить все эти цифры с реальной практикой компании.

## 8. Контент-план для рубрики «Публикации и исследования»
**Где:** [blog/index.html](blog/index.html)
Добавлена новая рубрика-заготовка под авторские научные публикации и разборы клинических данных. Сама рубрика создана, но статей в ней нет — нужен контент-план и авторские материалы.

## 9. Фото и инфографика
**Где:** не привязано к конкретному месту в коде
В репозитории нет неиспользуемых изображений/иконок, которые можно было бы задействовать для разбавления текстовых блоков (`assets/img/` содержит только уже используемый логотип MAX; остальные графические файлы в корне — это фавиконки и og-cover, тоже уже задействованы). Нужны фото или инфографика от клиента или дизайнера.
